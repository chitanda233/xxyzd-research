1. 一局到底怎么跑

第一章的单局链路是：进入关卡 → 按脚本批次刷怪 → 击杀产生经验掉落 → 波末主动吸收遗漏经验 → 结算本波升级 → 从当前合法候选里做 Build 选择 → 下一波继续加压 → W10 精英硬门槛 → W15 Boss 硬门槛 → 收束掉落与结束表现 → 判星、结果展示 → 奖励与局外成长回流。

① 进入关卡装入章节规则与玩家配置
② 刷怪推进位置组、定时批次、随机组混合
③ 击杀掉落经验按本波总预算向怪物分配
④ 波末收束吸收残留经验，统一处理升级
⑤ Build 选择类别分池 + 合法性过滤 + 结果纠偏
⑥ 节点验收W10 精英、W15 Boss 检查输出成型

游戏把战斗与成长决策组织成相互衔接的阶段：关卡先规定每波经验预算，波末吸收遗漏经验，再处理技能选择。关卡压力与玩家获得的成长机会因此可以放在同一张节奏表上设计。

贯穿单局的两条支线：W6 / W11 / W15 开头插入独立 Punchboard 技能事件，完成后续接当前脚本；任一战斗阶段死亡时进入复活分支，成功后回战斗，放弃或不可用则转结束处理。普通升级、阶段事件和复活不能合并成同一种“暂停弹窗”。

4. 为什么可以说“一波约一升”

第一章的每波经验不是随怪物数量自然漂出来的，而是关卡层先给出一份明确的总预算。更关键的是，这 15 份预算的逐波累计值和玩家前 15 个升级阈值逐项完全相等。

节点本波经验累计波经验对应升级阈值含义
W1200200200第一波完整经验正好跨过第一个阈值
W570026502650进入W5前约4次；完成W5后约5次普通成长
W10110073007300进入W10前约9次；完成W10后约10次普通成长
W1520001480014800经验预算仍覆盖阈值，但没有普通波末 UI，不能机械计为第 15 次常规三选一

经验按本波总预算分配给不同怪物。重怪可以分到更多经验，密集小怪可以拆成更多份，怪物数量与成长次数因此不必同比变化。关卡先决定成长预算，再安排玩家获得这份预算的战斗过程。

波末还会检查场上是否留有经验掉落；如果还有，会主动执行 AbsorbAll，等待经验动画进入可升级状态，再把待处理升级送入选技能队列。其设计作用是：经验不是只负责奖励击杀，它还承担“把玩家准时送到下一次 Build 决策”的节奏控制。

5. 三选一：逐张抽类别，再从合法候选中选技能

主线配置SkillType=2，使用专门的DankeSkillCreator。一次普通成长目标候选数为3：每张分别调用随机，先处理可用类别，再按池内权重取技能。类别基础权重是[0,200,300,300]，不能解释为白绿蓝紫品质概率。

① 确认入口引导覆盖或普通随机
② 选择候选池本局Init计数决定初始池/常规池
③ 处理当前构筑槽位、已学/待学、前置与互斥
④ 逐张加权抽取类别权重与池内技能权重
⑤ 补位和纠偏去重、轮转补池，全被动时尝试补武器
⑥ 选择并更新推进升星、分支与配方候选

章节决定技能权重列：第一章取Weight_1，而不是一律取默认Weight。初始池有10个武器入口，常规池有11武器+7被动入口；零权重或不合法的入口不会自动成为可选项。Init消费逻辑已确认，新开局计数赋值仍未闭合。

只有类别1与2可用且没有升档、刷新等修正时，对应类别抽签才是40%被动、60%武器；这不是最终三张的组成。刷新复用已保存类别索引，qualityUp处理索引升档；不能套用其他随机器的整组品质规则。

章节保护：第2—10章NewPlayerProtect含3，且WorldType=1、未持有机炮入口10000101时，尝试给机炮、冰刃弹、灼热射线临时增权10%，抽后撤销。第一章数组为空。本分支不直接判断账号新旧；也不意味着最终概率加10个百分点。

长期同类型增权未在本APK应用fallback中实现，不用于概率推算。完整概率分层、引导/初始池差异与22条进化配方见三选一、宝箱怪与武器进化专题；查看规则数据。

6. Build 怎么从一张牌长成完整路线

局内Build按配置分为四层：11 个武器入口、7 个通用模块、57 个武器分支、以及 111 个深层强化加 22 个突破节点。这些数量表示配置入口，不等于每次抽取的合法候选数量或线上开放数量。

武器主线

首次获得决定攻击方式，后续通过 NextSkill 推进星级与阶段。

武器分支

主线升级时可挂接归属武器的 104 系分支，形成弹道、伤害、频率与副作用差异。

通用模块

攻击、生命、冷却、暴击、维修等既提供泛用收益，也充当部分武器突破的配方件。

突破 / 深层强化

达到指定武器节点并拥有对应模块后，解锁 105 系突破和更深层的 101 系强化。

以速射机炮为例：首次获得后，主线继续升级；二星以后会挂接自己的 104 系分支，其中既有纯攻击强化，也有“增加正向子弹但降低攻击力”这种带取舍的改造。基础分支到3星节点后，如果玩家同时拿到暴击模块，会将对应突破加入加权候选池；仍需抽到并选择，不会自动进化。灼热射线也共享暴击模块作为自己的突破组件，而冰刃弹则与“缩小！”模块形成另一条配方关系。

所以一条完整 Build 更接近：主武器 → 主线等级 → 武器专属分支 → 配套通用模块 → 突破 / 深层强化。同一个通用模块可以服务一到两条武器路线，这让早期选择既有方向感，又不会过早把玩家锁死。

7. W5、W10、W15 为什么要做成三种不同节点

节点玩家约已完成的成长决策关卡手段检查内容
W5入波前约4次普通成长刷新任务密度突然放大，不锁推进有没有形成最初的战斗方向；失败成本不能太重
W10入波前约9次普通成长，另有W6阶段事件精英 310008 + 必须击杀；击杀后截断未执行刷新主输出链是否已经具有足够单体/持续伤害
W15Boss 前已有 14 个明确的常规波末成长节点Boss 340002 + 更高 HP 倍率 + 必须击杀武器、分支、模块、突破是否真正形成完整 Build

策划解读：这种编排让三处节点承担不同的验收职责。W5 允许玩家在 Build 尚未成熟时体验一次明显峰值，却不通过硬门槛把坏随机直接判死；W10 再开始要求输出成型；W15 才做最终验收。推进规则是：W10/W15 的门槛验收对象是 Type 201 精英或 Type 3 Boss：特殊目标清零后会清除尚未执行的怪物创建计划，而不是要求未来定时批次全部刷完。普通怪在这里更多承担干扰与环境压力，关键目标才是节奏开关。

8. 阶段技能事件：三次额外的 Build 介入

第一章在105s（W6）、240s（W11）、345s（W15）各配置一次 Punchboard。三条都是独立事件任务，不生成敌人；W15 的 Boss 任务另在347s。这里是脚本时钟相差2秒，不能理解为玩家只有2秒完成操作。[F15]

节点前一个验收后续用途：策划解读
W6开头W5强敌演出与软高潮前段成长后第一次改变技能构成，接中段混合压力
W11开头W10精英击杀锁中盘验收后再次调整，进入终盘压力
W15开头W14最后普通波Boss前最后一次阶段介入，其结果实际影响最终验收

它使用独立状态、结束事件和技能池，维护已有技能、新技能、补位与依赖关系；数量也走加权随机，并受角色属性和当前技能状态修正。因此不能把它写成“额外一次普通三选一”，也不能承诺固定赠送五个技能。

策划解读：第一章同时存在两条成长节奏：14个明确的普通波末成长节点，加上3次阶段技能事件。阶段事件基础数量档为1/3/5，未修正权重60/30/10；已有不同战斗技能组≤4时关闭5档。事件次数与数量档都不等于净增技能数量。其收益、损失和替换细节未完全闭合，不能据此推算Boss前固定持有多少技能。

9. 资源与生存：死亡、复活与续局

资源作用不能混用的口径
局内经验击杀产出、吸收后累积升级，波末消费升级次数不同于结果页的局外经验收益
生命与回复支撑持续战斗，并参与终局满血目标第一章回血相关配置0.04，不足以单独证明“每个血包回4%最大生命”
装备等掉落战斗记录与结束吸收流程处理吸入掉落不等于失败后全部保留或服务端已发放

死亡后的资格与选择

自身复活判定顺序是：技能复活剩余次数 → 满血复活概率属性 → 普通复活概率属性 → 剩余弹窗复活资格 → 无可用复活分支。两种概率属性与同一次传入随机值比较，不能把它们当成两次独立抽签后相加。技能复活与属性复活可直接走角色恢复；弹窗复活才等待玩家选择。[F18～F22]

① 角色死亡记录并进入死亡状态
② 判定资格依次检查技能、属性、剩余次数
③ 等待选择适用时展示购买/广告/放弃
④ 应用复活处理计数、恢复角色并触发事件
⑤ 返回战斗激活战斗态
⑥ 恢复成长尝试续接被打断的波末升级

购买成功进入普通弹窗复活路径；广告成功先增加广告计数，再进入该复活路径；关闭则进入不复活的后续处理。恢复角色后重新进入战斗，并尝试续接被打断的波末成长。

计数规则影响评价：购买与广告复活消耗弹窗复活资格，并增加用于判星的已用次数；技能和概率复活不经此分支增加该次数。不同来源的复活对评价的影响不同。

弹窗绑定商品601，内置价格50钻石；广告入口还有资格检查。这证明入口和基线价格，不能推导每局一定可购买或广告次数无限。第一章的 ResurrectionTimes=0也不能覆盖技能和概率复活分支。无敌时长、清弹范围和敌人血量保留仍需角色恢复/敌人系统的更细验证，不以“续接战斗”一并推定。

策划解读：复活保住的是已经投入的时间和 Build；评价却对不同复活来源作区别。技能型容错可能保留更高的通关质量，弹窗续局则在“先过关”和“保星”之间形成取舍，不能简单把所有复活归为同一失败成本。

10. 终局：先收束本局，再判断通关质量

W15只有Boss击杀锁，没有W1～W14的普通波末升级UI。结束态另有结束表现、装备/经验掉落检查与吸收流程，随后由结束事件承接结果数据。Boss的2000经验覆盖一个等级预算，不证明它必定再给一次有战斗用途的三选一。终局吸收与普通波末成长应分别画出。[F23～F25]

三星看什么：配置文案与运行判定对照

第一章目标已核对实现对玩家决策的意义
成功通关本章成功结果且启用星级评价时参与判定先完成本局胜利目标，再讨论质量
未使用复活以已用复活数对比阈值0；本基线计数路径仅增加弹窗复活购买/广告续局可能保住通关，但失去这一星；不能直接套到技能复活
通关时生命值100%成功结果收集星级时检查HP百分比阈值100指向终局状态，而非全程不受击；收集前回复具有价值

满血目标面向结束时的状态，并非全程不受击。收集星级前的回复因此具有潜在价值；额外间接检查、线上热更新及服务端覆核未验证。

结算与回流：三种奖励入口分别理解

入口已知边界策划作用
章节完成奖励章节有独立配置；数组结构与实际发放尚未全部核实提供再次挑战的收益预期
首通奖励独立于完成奖励；不能默认为每局重复发放推动章节推进
累计星级奖励有独立档位和奖励表；不等于本局结果页立即到账把满血与少用弹窗复活转为重玩目标

结果界面具备胜败、星级、经验进度、击杀数和伤害统计等呈现能力。结合奖励入口，完整的策划闭环是：本局表现 → 判断是输出不足还是生存不足 → 调整构筑或局外配置 → 再挑战。这是系统关系的解释；失败保留比例、实际到账数量、首通解锁后续章节的服务端条件尚未核对，不能把界面能力写成已验证收益。

11. 这些设计为什么这样做

第一层价值是可控节奏。经验预算与等级阈值完全对齐，让策划能够非常稳定地知道“第几波之前玩家大约做过几次选择”，因此怪物压力、精英/Boss 与 Build 成长可以在同一张时间表上调，而不是两个系统各自漂移。

第二层价值是减少 Roguelike 随机的挫败尾部。候选仍然随机，所以每局会有变化；但逐张类别抽取、前置过滤、父子分支、独立初始池和全被动纠偏，有助于维持构筑的连续性；实际降低挫败的幅度仍需运行数据验证。长期同类增权未在本基线应用，不计入这一设计解释。

第三层价值是让选择同时具备短期收益和长期路线承诺。拿一个通用模块不仅改变当前数值，还可能成为某把武器未来突破的配方件；拿一把武器也不只是增加一个自动攻击，而是开启后续主线与分支池。这样三选一里的一张牌会同时影响“现在打得更轻松”和“后面能不能完成质变”，同一张牌因此同时包含即时收益与路线价值。

第四层价值是支撑重复游玩而不完全依赖重运营。相同章节可以因为武器入口、分支取舍、配套模块和突破顺序不同形成不同战斗形态；结构化随机控制旨在缓解候选与成长路线脱节。至于这些结构具体怎样与付费入口连接，还需要外围经济与商业化单独反拆，当前局内证据不足以直接推导付费结论。

12. 适用范围

本报告适用于客户端1.0.16、第一章基础配置。脚本时间不等于真实游玩用时，配置怪量不等于每局实际刷出量，入口数量不等于当次候选数。策划解读是对已知结构的解释，不代表玩家体验或平衡测试结果。

初始池的新局赋值、阶段事件的精确收益、复活细节、末次成长表现及奖励到账仍有未验证部分。它们不被用于推算确定的技能数量、通关时长或收益。具体问题、已查范围和再次深查所需材料保存在独立数据层。
