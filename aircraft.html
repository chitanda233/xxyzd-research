AIRCRAFT / SKIN DESIGN BREAKDOWN

战机与“皮肤”策划反拆

这里不按程序表名解释系统，而按玩家实际感知来拆：游戏配置虽然把 10101–10108 叫作 Skin，但从品质、独立战斗实体、五星成长与专属机制看，它们实际上承担的是“不同战机形态 / 角色卡”的功能。

策划结论先行

第一，这不是传统皮肤系统。基础 Role_Role 只有一个战机入口 10100，但下面挂了 8 个 Skin。每个 Skin 都有独立 RoleEntity、品质和五星成长；从 10103 开始，每一星还会改变专属战斗机制。玩家实际获得的不是“同一架飞机换个样子”，而是“同一角色槽下切换不同机体玩法”。

第二，8 架机体的基础战斗模板被刻意做成一致。100001–100009 的基础 HP=600、Attack=100、MoveSpeed=70、FireCD=0.1、初始 WeaponID=100003，基础属性也一致。换句话说，设计没有靠一堆基础面板制造差异，而是把差异集中到“品质 + 升星属性 + 专属机制”三件事上。

第三，品质不是单纯数值颜色，而是机制复杂度分层。品质 40 的守卫/游侠只有攻击成长；品质 50 的三架机体开始拥有完整五星专属技能；品质 60 的三架机体不仅星级攻击曲线更高，技能链也明显更完整，出现腐蚀、持续增伤、连携、自强化、闪避联动等复合机制。

第四，升星的核心价值不是“+攻击”，而是逐步完成一套玩法。1 星通常给核心招牌技能，后续星级增加伤害、覆盖、续航、触发条件或循环效率，最终把一个简单的周期技能变成完整 Build。这一点是这套战机系统最值得策划关注的地方。

系统真正的分层方式

品质 40：入门机体。守卫、游侠。五星攻击配置为 80 → 160 → 240 → 320 → 400，没有专属 Feature 技能。功能是让玩家先理解“换机体 + 升星”本身，而不是立即承受复杂机制。
品质 50：玩法型机体。暗夜刀锋、天使号、飞鹰号。同样使用 80 → 400 的攻击成长，但从 1 星开始就解锁独立机制，五星分别围绕受击反击、周期弹幕、周期轰炸成长。
品质 60：高级玩法型机体。毒蝎、黑武士、幻影。攻击配置提高为 100 → 200 → 300 → 400 → 500，同时专属技能更强调状态、循环和自我联动。品质提升同时卖“更高数值”和“更完整玩法”。

真正的养成结构：共享母体 + 机体形态

这套系统不是“每换一架飞机就从 1 级重练”。基础 Role 10100 自己有一条长期成长线：等级 1–160，并由 0–7 星逐段开放等级上限，依次是 20 / 40 / 60 / 80 / 100 / 120 / 140 / 160。机体形态 10101–10108 则在这条母体成长之上，再拥有自己的 5 星属性与专属机制。

共享母体负责长期等级、基础 HP/攻击成长、等级上限与通用战力。
机体形态负责外观识别、品质和独立五星玩法链。
玩家换机不是完全推倒重练，而是在已有母体战力上追一个新玩法分支。

基础等级升级消耗金币与星币。按当前 160 条等级配置累计，升到 20 / 40 / 60 / 80 / 100 / 120 / 140 / 160 级时，金币累计约为 5.0 万 / 19.6 万 / 69.3 万 / 250.3 万 / 684.3 万 / 1387.3 万 / 2317.3 万 / 3372.3 万；星币累计约为 2680 / 1.08 万 / 2.93 万 / 6.86 万 / 14.25 万 / 25.48 万 / 38.94 万 / 52.44 万。

策划意义：大额、长期、稳定消耗放在共享母体；新机体不需要重新复制一整套等级坑，而是通过独立五星机制制造新的追求。这能同时保留长期资源回收和“抽到/解锁新机立刻可玩”的爽感，是一套很适合多机体 STG 的养成分层。

五星成长节奏：这套设计为什么有效

六架机制机体虽然效果完全不同，但升级节奏非常一致：1 星先交付核心幻想，2 星通常强化直接输出，3 星加入新的规则或联动，4 星扩大覆盖/持续/循环，5 星给最终形态。因此每一星都很容易写成“玩家看得懂的卖点”，而不是后台数值。

这也是它比纯“升星 +5% 攻击”更强的地方：玩家追求重复获取时，目标不仅是战力，而是“我的机体还差一个关键能力没完成”。暗夜刀锋 3 星的维修箱、黑武士 3 星的次元斩、幻影 2 星的闪避减 CD，都是典型的玩法里程碑。

从策划角度看，它实际上是一套“低成本多角色”方案

底层只维护一套基础战机参数与初始武器，8 个形态共享 HP、攻击、移速、射速等基础框架。差异集中到模型、品质和一条五星技能链。这样新增一架“战机”时，不需要重做完整角色系统，只需增加一个形态、一条技能主题和一套星级递进。

对小团队尤其值得注意：视觉上是 8 架飞机，系统上仍然是一套 Role。它用很低的系统复杂度实现了“收集多机体”的内容感。不过副作用也很明显——如果前台真的把这些东西叫“皮肤”，玩家会低估它们的战斗差异；从产品表达上更适合包装成“机体 / 战机型号”，皮肤只用于纯外观变化。

这套体系的商业化与留存作用

品质 40 提供低成本入门目标，品质 50 开始让玩家体验“不同机体有不同玩法”，品质 60 再同时抬数值上限和机制完整度。这形成了一条很标准的收集驱动力：先解锁新外观 → 发现它有独立技能 → 继续升星补完技能 → 追求高品质机体的完整循环。

当前 Skin 的解锁消耗直接使用自身 ID 对应的道具，说明机体形态天然适合接碎片、抽取、活动奖励或商店兑换；但 ShopGoodsId 在这张表里为 0，所以具体来源不能只凭这张表判断，我不会在这里猜获取渠道。

对《摩玩飞机大战》最值得借的不是“8 个皮肤”，而是这个结构

如果从设计方法上抽象，它的核心是：统一基础战机框架 + 少量机体主题 + 每个主题一条 5 阶机制成长链。这样既能让玩家明显感觉“换了一架飞机”，又不会把数值、武器、移动、碰撞、升级全部做成独立角色系统。对于 STG 小团队，这比堆几十架只有攻击数值不同的飞机更有效率。
