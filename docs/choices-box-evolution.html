1. 三种成长机会，各自负责什么

先区分决策权和发放方式，才能判断玩家什么时候应该停下来选择、什么时候获得成批强化。

什么情况下系统做什么玩家结果／策划意义
普通升级生成目标3个合法候选，由玩家选取玩家决定下一步拿新路线、升已有武器，还是补模块
飞机接触主线宝箱抽取1／3／5项奖励，按结果整批学习集中推进构筑，奖励可以升级或覆盖已有技能
满足进化配方并取得对应节点处理武器专属的后续选择将早期武器和模块的搭配转化为进阶能力

2. 三选一规则：先看当前能学什么，再进行随机

抽取池随当前构筑变化。一张牌被选中后，后续升级、互斥和配方条件都会改变，下一次选择的意义也会变化。

什么情况下系统做什么玩家结果／策划意义
本次有引导指定候选直接使用该列表，用后清空这次成长是指定教学内容
进入常规抽取，初始池计数尚未耗尽使用独立初始池；消耗后转常规池初始池有10个武器入口，常规池有11武器、7模块入口；合法候选还需筛选
对应槽位已满限制新增该类路线，保留符合条件的已有路线成长限制铺开宽度，继续提供纵向成长
存在前置、互斥或星级条件先筛选合法项，再逐张抽取、去重和补位不是把全表所有词条平均摆出来
一组结果全部是被动且存在合法武器候选尝试用武器候选替换一个位置减少完全缺少输出方向的结果，但不保证必出新武器

3. 如何读概率：类别倾向与具体词条分开

基础类别权重为被动200、武器300、特殊升级300。先确认哪些类别有效，再看类别内的合法技能与权重，最后还有补位和整组调整。

什么情况下系统做什么玩家结果／策划意义
仅被动与武器类别有效，且没有其他修正类别抽签为40%被动、60%武器这是单次类别抽签，不是最终一屏三张的比例
三个类别都有效，且没有其他修正类别抽签为25%、37.5%、37.5%不能把这组数字称作稀有度概率
第2—10章且未持有机炮入口，满足主线保护条件机炮、冰刃弹、灼热射线临时增加10%相对权重，抽后撤销引导方向，不是必中，也不是加10个百分点
同一个玩家换到其他章节或改变构筑章节权重与合法候选改变单个词条没有脱离状态的固定最终百分比

4. 主线接触宝箱：出现、拾取、数量和内容

宝箱由章节脚本安排。飞机接触宝箱并完成拾取进度后，进入批量词条奖励。主线位置默认固定；配置的接触累积时间为0.2秒，实际触发还受帧进度和状态处理影响。

什么情况下系统做什么玩家结果／策划意义
大多数15波章节第6、11、15波安排宝箱在阶段切换与终局前补强
第5、15、25、35、45、55、65章（10波）第4、7、10波安排宝箱压缩波数时仍保留3次集中成长
第10章／第60章分别仅在11、15波／6、15波安排这两章是2次宝箱的例外
已有不同战斗技能组≤4，无额外修正1项66.67%；3项33.33%；5项0%五项档被构筑门槛关闭
已有不同战斗技能组>4，无额外修正1项60%；3项30%；5项10%允许更大的批量成长
有五项档权重加成且通过门槛修改五项权重后重新归一化例如权重翻倍为20，最终概率是20/110≈18.18%

5. 宝箱具体发什么：围绕升级候选逐项生成

先从当前构筑对应的技能池提取二星及以上升级条目，保留前置和权重；再按合法类别和池内权重逐项抽取。过程中处理后续升级与进化依赖，不足时调用补位池，最后整理连续升级并批量发放。

什么情况下系统做什么玩家结果／策划意义
抽取前已有可用升级路线从这类升级条目开始构建奖励池宝箱主要推进构筑，不能理解为全技能表随机送新武器
一项奖励改变后续升级条件更新后续技能与依赖，再继续生成同一箱的后续奖励会受前面结果影响
升级候选不够用补位池补充仍需满足补位规则，不保证每项都是新技能
批量奖励产生待处理武器特殊节点奖励完成后接武器专属选择只有满足条件才追加选择

6. 具体案例：机炮怎样走到进化

基础分支中，机炮升到3星节点，并持有暴击模块后，系统把对应进化节点加入加权候选池。玩家还需取得该节点，才会进入后续武器特殊选择。

什么情况下系统做什么玩家结果／策划意义
只有3星机炮，缺暴击模块该配方尚未满足后续拿模块有路线价值
先有暴击模块，后来机炮到3星满足配方并解锁候选配方支持组件的不同取得顺序
两项条件都满足，但还未取得进化节点进化仍停留在候选池“配方齐了”不等于立即自动进化
采用B配置分支机炮3星改走另一条特殊升级连接，最高星级也不同不能套用基础配方，也不能把B直接称为老玩家版

完整规则与数据：候选、宝箱、进化

普通三选一：从入口到落地的七步

① 先检查本次是否有引导指定列表，有则直接使用并清空。② 否则根据本局初始池计数选起步池或常规池。③ 结合章节技能权重列、已学技能、武器和被动槽位、前置与互斥关系过滤。④ 每张候选独立做类别抽签，再按该类别内的有效权重取技能。⑤ 去重、补位；若整组三张没有武器类且池内仍有合法目标，尝试替换一张。⑥ 玩家选中后学习或覆盖，更新下一星、分支和配方候选。⑦ 存在待处理特殊节点时再进入武器专属选择。

本局初始池计数>0才使用10个武器入口；计数消费已确认，但“新账号必然怎样赋值”尚未闭合。常规池18个入口只是配置规模。基础武器与被动槽位各4个；B分支槽位及开放条件另有配置。

概率计算：同一个权重在不同条件下为什么不同

类别基础权重为被动200、武器300、特殊升级300。仅被动与武器有效时，单次类别抽取是200/500=40%与300/500=60%；三类都有效则为25%／37.5%／37.5%。这一步之后仍要在类别内抽具体技能、处理同屏去重及补位，因此不是最终每屏比例。

第2—10章且WorldType=1、未持有机炮入口时，机炮、冰刃弹、灼热射线的有效入口权重临时提高10%，抽后撤销。这是相对权重乘数，不是最终出现率增加10个百分点。刷新复用保存的类别索引；高阶属性走其他判断，不能随意并入类别权重。

某个技能的可复算最终概率必须给定本次的章节、B分支、已有技能与星级、槽位、初始池计数、引导覆盖、属性和当次合法池。缺任一状态，只能报告相对权重。

接触宝箱：出现、拾取、数量档、内容池和到账

宝箱出现由章节任务的missinType=9固定安排：70个可见主线章节基础分支合计208次，B分支另有208次。当前全部任务里没有RandomNpc=9，因而源码中的随机遗漏补偿分支在这套配置下不触发；不能给固定宝箱再套一个“掉落概率”。当前证据也没有把某个击杀怪物接到这条奖励箱链上。

章节事件先创建宝箱实体。飞机接触宝箱后累积拾取进度：配置0.2秒，离开时以10秒的回退参数处理；状态和缓存还会门控，因此0.2秒只是配置阈值。进入宝箱奖励状态后，先决定1、3或5项，再逐项生成词条，最后批量学习。

数量基础权重为60、0、30、0、10，故超过4个不同战斗技能组且无修正时分别为60%／30%／10%。组数不超过4时五项权重清零，剩余60:30重新归一化为66.67%给1项、33.33%给3项。五项概率加成先改变末档权重，之后还要过组数门槛；若原10权重翻倍为20且门槛已通过，五项概率是20/(60+30+20)=18.18%。

内容池先从当前构筑筛二星及以上的已有路线升级，保留权重、前置与技能限制。内部按容量16模拟候选，逐项更新后续升级与进化依赖；不够则从补位池补足，整理依赖连续性后得到最终1／3／5项。16是内部容量，不是奖励数。部分结果会升级或覆盖现有技能，不能当作净新增词条数。宝箱后若存在待处理的武器特殊节点，会继续进入该节点的专属选择。

进化配方：解锁和取得是两件事

基础分支的配方把武器节点和指定模块关联。例如速射机炮到10000103且已有暴击模块11000701，系统将10500101以配置权重5000加入候选池。玩家仍需在后续合法抽取中取得该节点；若该节点为特殊升级，才打开后续武器专属选择。B分支在同一配方函数提前返回，使用另一条配置连接，不按账号新老解读。
