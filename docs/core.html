策划归纳

1. 先确定这局要让玩家经历什么

以第一章为例，前段让玩家建立输出方式，中段用精英检验成型程度，后段让武器、模块和进化一起接受首领检验。以下“阶段职责”是对配置的策划归纳。

什么情况下系统做什么玩家结果／策划意义
第1—4波：建立方向逐波提供经验和成长机会先形成能够持续战斗的输出与生存组合
第5波：第一次压力峰密集刷新强敌，但不设特定目标击杀锁提前暴露构筑短板，同时允许流程继续
第6—10波：补强后检验第6波宝箱；第10波必须击杀精英先补强，再确认主输出是否足够
第11—15波：成型与终验第11、15波宝箱；第15波必须击杀首领让前面的选择在最终战斗中产生可感知结果

2. 一局推进规则：达到什么条件，才做下一件事

把这张表作为流程骨架。普通波、击杀门槛、成长弹窗和终局分别有自己的结束条件。

什么情况下系统做什么玩家结果／策划意义
入场准备完成装入章节、玩家战斗配置及本局成长状态，开始第一波确定本局的规则和战力起点
波次脚本执行到刷新节点按固定位置、编队或随机组合投放怪物玩家开始处理当前战斗压力
普通波进入波末，场上还有经验吸收残留经验，等待经验处理，再结算待升级次数成长机会不会只依赖玩家绕路捡经验
有待处理的普通升级提供目标3个合法候选，玩家选取后更新构筑一次决策改变后续候选和战斗表现
精英／首领门槛波的关键目标尚存继续等待关键目标死亡单靠拖过脚本时点不能通过
关键目标清零清理尚未执行的刷新计划，推进后续流程实战刷出数量可以低于完整脚本预算
最终首领死亡收束掉落和结束表现，进入结果与评价终局不再等同普通波末成长

3. 成长节奏：先给预算，再安排玩家怎样拿到

第一章每波经验累计值与前15个升级阈值逐项对齐；前14波有明确的普通波末成长流程。这说明经验在这里承担进度控制，而不只是击杀奖励。

节点具体数据怎样用于策划
完成第1波本波200经验，累计200预算对齐第一个升级阈值
完成第5波本波700，累计2,650在首次压力峰后达到对应成长进度
完成第10波本波1,100，累计7,300中盘击杀验收后继续推进成长
第15波终局本波预算2,000，总计14,800有经验预算，但不能计作一次必然可用于战斗的终局三选一

4. 走一遍具体情境：第5波结束到第10波精英

5. 失败与通关质量：保住进度，也保留取舍

死亡处理先看直接复活能力，再看弹窗复活资格。第一章评价还区分是否使用计数内的复活，以及结束时是否满血。

什么情况下系统做什么玩家结果／策划意义
角色死亡且有可用技能复活优先使用技能复活能力型容错先发挥作用
技能复活不可用依次检查满血复活概率、普通复活概率，再检查弹窗资格这些概率并非两次独立抽签相加
弹窗购买或广告成功扣相应资格、恢复角色并返回战斗，尝试续接成长保住时间与构筑，但会增加该路径的已用复活计数
无可用复活或放弃进入结束处理本局转入失败结果
成功通关并收集星级第一章检查复活计数阈值0、生命百分比阈值100“满血过关”看终局状态，不要求全程无伤

单局状态衔接的判断顺序

每波读取脚本任务，位置组、组合编队与随机路线可能在同一任务中并行；按任务和模板时点创建怪物。普通波结束先收场上经验掉落，经验动画结束后按待升级次数逐次展示候选，全部处理后才进入下一波。

第10波与第15波的推进条件是特殊目标死亡；目标死亡后可清除尚未执行的怪物计划。因此完整计划数和一次实战的实际生成、击杀数不同。第6、11、15波的宝箱是独立事件，拾取与批量成长完成后继续本波流程。终局先收束掉落再结算星级、奖励。

数据依据：in-run/facts.json · in-run/flow.json

死亡、复活与评价逐步判断

死亡后优先检查技能剩余复活次数；其后将满血复活概率、普通复活概率与同一个随机值比较，再查弹窗复活资格。这两种概率不是独立掷两次骰。

弹窗购买成功或广告成功走类型3复活：购买入口绑定商品601、内置价格50钻石；广告先增加广告计数，再进入类型3。该类型会消耗资格并增加评价使用的复活计数。技能和属性复活不沿这条计数路径。成功恢复后返回战斗，并尝试续接被打断的波末成长。

成功通关且启用星级收集时，第一章检查通关、已计入的复活次数不超过0、结果收集时生命百分比达到100。满血条件看结束时，不是全程无伤。

数据依据：in-run/facts.json · in-run/inputs/Chapter_MainChapter.json

6. 怎样借鉴成自己的关卡方案

先排成长节点，再排压力节点；每个压力峰都写清“想验收什么”。不要只填写怪物数量和血量。

策划目标可参考的安排需要验证的体验指标
希望前段让玩家尝试方向先给数次成长，再安排可推进的压力峰观察候选选择分布、受伤率与首次失败波次
希望中盘要求输出成型把补强机会放在检验之前，再设置击杀门槛观察关键目标击杀时长与构筑差异
希望最后一次成长有明确价值把阶段宝箱放在首领战前观察奖励是否实际改善首领战能力
希望鼓励高质量通关将通关、复活使用和终局生命分别评价观察续局率和重复挑战目标
