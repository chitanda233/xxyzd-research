武器构筑：一张选择怎样改变后续路线

武器定义攻击方式，专属分支改变使用特点，通用模块同时提供即时收益和配方价值，进阶节点兑现长期搭配。构筑设计要同时照顾当前战斗和未来目标。

运行规则与案例

1. 用四层成长组织武器路线

当前配置有11个武器入口、7个通用模块入口、57个分支强化入口、111个深层强化入口及22个进阶节点。这些是内容规模，不是每屏可选数量。

什么情况下系统做什么玩家结果／策划意义
首次获得武器建立一种攻击方式玩家开始选择主输出方向
继续提升武器主线推进星级与下一阶段提高已经选择的路线价值
选择专属分支改变弹数、伤害、频率等特点，部分带负面取舍让同一武器有不同成长形态
选择通用模块提供泛用属性，并可能成为进化组件一张牌兼有短期和长期价值
取得进化／深层节点在条件满足后继续推进专属能力让早期组合产生后期回报

2. 三个典型选择情境

下面的“考虑方向”是策划层的决策解释，不是对所有版本与数值环境通用的最优攻略。

玩家状态发生什么选择设计上形成的取舍
前段缺少稳定输出新武器入口与已有武器升级竞争新路线扩大覆盖，已有路线升级集中投入
已有主武器，模块槽尚有空间即时属性模块与进化配套模块竞争配套模块的价值包含未来配方，而非只有本次面板变化
槽位接近满额新增路线受限，后续更多依赖已持有路线成长槽位决定构筑宽度，升级深度决定后续成长空间
临近首领战，配方尚未兑现即时伤害与未来潜在进化竞争剩余成长机会会改变同一张牌的价值

3. 机炮路线案例：从开局输出到配方追求

机炮先通过主线升星推进；二星可挂接专属分支，其中存在增加正向子弹但降低攻击力的取舍。基础分支到3星且持有暴击模块时，可以解锁对应进化候选；获得候选后才继续特殊选择。

什么情况下系统做什么玩家结果／策划意义
想扩大正面覆盖选择增加正向子弹的分支，同时接受攻击力代价要按弹数、命中与单体表现评估，不只看单发数字
想围绕进化规划推进机炮到配方要求的星级，并取得暴击模块构筑目标由多个选择共同完成
已拿暴击模块但武器路线未定暴击模块还可关联灼热射线的突破路线一个泛用组件可以保留后续转向空间

4. 宽度与深度怎样一起控制

基础配置的武器与被动槽位各4个；B分支采用另一套槽位与开放规则。有限槽位避免无限铺开，而已有路线的主线、分支和后续节点提供持续成长。

内容设计手段主要改变什么检查事项
开放更多新武器提高构筑宽度需要检查每种武器是否仍有存在感
提供更多同武器分支提高路线内部变化需要明确分支是叠加、替换还是互斥
提供更深星级与进阶节点延长路线追求需要让成长机会与关卡长度匹配
用泛用模块连接多种配方降低过早锁死路线的程度验证组件是否具有足够即时收益

5. 可复用的武器设计卡

每条武器路线都应先回答以下问题，再落到具体词条表。

设计项要填的具体规则目的
战斗身份擅长单体、清杂、持续区域还是近身输出？让玩家知道为什么拿它
主线成长哪一星只加数值，哪一星引入新能力？给成长节奏设置可感知节点
分支取舍拿到什么收益，放弃什么能力？避免所有分支只剩更大的相同数字
模块连接哪个模块既有即时价值，又服务进阶？形成跨选择的长期目标
兑现节点满足哪些条件、从何处取得、是否还需选择？避免配方提示与实际获得流程脱节
