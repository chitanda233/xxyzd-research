字段怎么读

字段本页解释注意事项
SkillType技能类型枚举/分类字段，是随机选牌权重研究的重要键。当前没有在网页里擅自给每个数字命名；需要继续反查枚举和调用逻辑。
Quality / SkillStar品质与技能星级相关配置，可用于筛选技能成长层级。不能直接把 Quality 数字映射成玩家看到的稀有度颜色，除非语言/UI 表有明确证据。
UpgradeSkillId升级后续节点，是构建技能升级树的关键字段。A/B 两套字段均保留，暂不自行解释 A/B 代表什么模式。
PreSkillIds / NeedSkills前置或依赖关系。筛选执行的先后顺序要结合原生逻辑。
RejectSkills / BanSkillS互斥或禁止关系。不同字段可能作用于不同阶段，不能合并成一个规则。
CoverSkill / NextSkill技能覆盖与后续引用。下一步适合做成可视化关系图。
IsBattleSkill / IsRealSkill / IsSuper用于快速区分技能记录性质的原始标记。标记为 0 不等于“无效”，只代表该字段当前值为 0。
_中文名称 / _中文说明模板研究脚本根据语言表附加的便捷字段。说明模板里的占位符没有统一替换，精确参数仍应回到原技能字段。
