PILOT CONFIG FAMILY

Pilot 配置组

客户端存在独立的 Pilot 配置族：12 条本体、56 条升星、12 条动画映射和 2 条总配置。它与 WeaponType、SkillPreview、飞机/武器展示资源强绑定，因此本页按“配置体系”拆解，不先把它套进传统 RPG 驾驶员概念。

为什么单独拆

Pilot_Pilot 每条记录都包含 WeaponType、品质、解锁资源、展示模型和 SkillPreview。从第二条开始，多个记录的 ShowModel 实际指向 PlaneUI/model_plane_*，PilotNameId 又复用了 Weapon_* 键。这种数据形态说明它和武器/战机表现层存在明显复用，不能只凭表名断言它就是“人物驾驶员”。

研究口径：页面保留官方配置命名 Pilot，同时把字段事实列清楚。等后续把 UI 界面、语言表和调用类一起对上后，再决定玩家侧应该翻译成“驾驶员”“机师”还是另一套战机搭配系统。

和武器体系的交叉

Pilot 的 WeaponType 是连续编号，而 SkillPreview 直接引用 106… 技能 ID；这和 AirplaneGun 星级特性里出现的技能 ID 属于同一层连接线。后续研究会把 Pilot → WeaponType → Weapon → FeatureSkill → 局内词条做成一张关系图。

升星与动画

Pilot_Star 有 56 条记录，说明该配置族有独立的长期成长；Pilot_PilotAnim 则把 PilotID、RoleID 与动画资源连接起来。下一步需要把 56 条升星记录按 Pilot ID 分组，确认不同对象的最大星级是否一致，以及升星究竟增加面板、解锁技能还是两者都有。
